# Contenido del paquete de entrega

`NOVA-HUD-6.0.1-Studio-Demo.zip` contiene:

- `NOVA-HUD-6.0.1-Studio-Demo.rbxlx`: lugar generado por Rojo;
- `demo.project.json`: proyecto autorizado completo;
- `default.project.json`: núcleo de solo lectura por defecto;
- `rokit.toml`: versión reproducible de Rojo;
- `src/`: arquitectura NOVA 6.0;
- `demo/`: catálogo, servidor, proveedor, UI y arnés de Studio;
- `tests/`: pruebas puras ejecutables con Luau CLI;
- `scripts/check.sh`: política estática y pruebas;
- `scripts/package_demo.sh`: construcción reproducible del paquete;
- `docs/`: instalación, arquitectura, validación, loader y plan de prueba.

El paquete no contiene credenciales, cookies, tokens, remotes privados ni
dependencias de un juego de terceros.
